## 术语

| 术语 | 定义 |
| --- | --- |
| 基准实现 | 最小实现：CPU 160 MHz，不使用 GUI 框架，可选子系统（触摸、RGB 指示灯、音频、电池计、MicroSD）全部关闭；组件版本取「版本基准」。验收界值与 `max_transfer_sz` 取值均以该实现为准 |

「版本基准」为组件版本组合，「基准实现」为运行时形态，两者所指不同。

## 版本基准

实测基准：

| 组件 | 版本 |
| --- | --- |
| ESP-IDF | 5.5.4 |
| espressif/esp_lcd_st77922 | 2.0.2 |
| espressif/esp_codec_dev | 1.6.2 |
| espressif/led_strip | 3.0.3 |
| espressif/cmake_utilities | 0.5.3 |

厂商验证组合（见厂商工程 `1-示例程序_Demo/ESP-IDF/3.5inch_ESP32-S3_LVGL/dependencies.lock`）：

| 组件 | 版本 |
| --- | --- |
| ESP-IDF | 5.4.2 |
| espressif/esp_lcd_st77922 | 1.0.3 |
| lvgl/lvgl | 8.4.0 |

`esp_lcd_st77922` 的 IDF 版本要求随大版本变化：1.0.3 为 `>5.0.4,!=5.1.1`，2.0.2 为 `>=5.4`。

## 覆盖边界

已实测：

| 功能 | 实测内容 |
| --- | --- |
| 显示 | QSPI 初始化、绘制、色彩、4 像素对齐 |
| 背光 | 通断 |
| 按键 | BOOT 键作普通输入 |
| 触摸 | 控制器在 0x55 应答，触点数上限返回 5，触点位置与坐标随手指变化 |
| 音频播放 | 编解码在 0x18 应答，经功放驱动扬声器发声 |
| RGB 指示灯 | 颜色按序输出 |

未实测或不完整：MicroSD、音频录音、电池计（部分实测）、背光 PWM 调光、OPI PSRAM、低功耗、峰值电流、发热、持续刷新率、横屏、器件型号取值、QSPI 时钟合规性。逐项状态见 [`07-open-items.md`](07-open-items.md) 第 1 节。
